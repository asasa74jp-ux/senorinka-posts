# format_bank.md — 型台帳

## 生きてる型（writer_rules.md の構文パターンと対応）

| 型 | 構造 | 実証(views) | 使う場面 |
| --- | --- | --- | --- |
| 1. リスト型 | 中黒箇条書きでNG習慣・兆候を列挙 | 未計測 | ファン化・自己観察系テーマ |
| 2. 誤解ほどき型 | 「〜と思われがち／でも本当は」で通念をほどく | 未計測 | 誤解の多いテーマの導入 |
| 3. ストーリー型 | 「鑑定でよく聞く話」枠の高解像度エピソード | 未計測 | 深いファン化・保存され狙い |
| 4. おまじない・浄化ワーク型 | 低ハードルな儀式の提案 | 未計測 | 実践型コンテンツで参加感を出したい時 |
| 5. 見極め型 | 表面的基準を否定→本質的観察ポイント→自問 | 未計測 | 相手/自分を見る目を養うテーマ |
| 6. 期間限定・開運タイミング型 | 星座別「動きやすい変化」ランキング | 未計測 | 短期の鮮度・エンタメ狙い |
| 7. 開運スポット紹介型 | 実在スポット＋体験談ミニエピソード | 未計測 | 保存・スクショされやすいネタ |
| 8. 共感型／告白型（エモ型） | 一人称独白、アドバイスなし | 未計測 | 深い共感・リプ誘発 |
| 9. 開運日カレンダー型 | 実在暦注＋事実確認必須 | 未計測 | 該当日限定の鮮度コンテンツ |

「実証(views)」列は fetch_today.py / daily_report.py が稼働し次第、実測値で埋める。

## 外部の型メモ（構造だけ学ぶ・文言流用禁止）

- hiyori_reishi_: ぶった切り接続、冒頭フックのブックエンド、同語反復の畳みかけ、二否定→一肯定カスケード、弱さの否定→リフレーム締め。おまじない・浄化ワーク型、見極め型、開運スポット紹介型の元ネタ
- sneesss（推定）: ストーリー型の高解像度化（セリフの一字一句引用、経過年数の具体化、核心の一行凝縮、非二元的な結び）
- 期間限定・開運タイミング型／開運日カレンダー型: 星座×暦注の吉日ランキング投稿の構造。金運・事業訴求とフォロー誘導・排他的な煽り文句は不採用、恋愛・ご縁の文脈に絞って移植
- 共感型／告白型: 一人称の生々しい独白＋忠告なしの型。感情の再定義（「本当につらいのは〜だと思ってた。でも本当は〜」）が有効
